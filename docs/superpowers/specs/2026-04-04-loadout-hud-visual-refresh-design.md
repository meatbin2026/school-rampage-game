## Loadout And HUD Visual Refresh

### Goal
Extend the new arcade-style homepage language into the pre-battle loadout screen and the in-battle HUD so the game feels cohesive, playful, and more like a mobile action game.

### Direction
- Turn character and starter-weapon cards into selection posters instead of plain option rows.
- Turn the loadout summary into a mission briefing card with stronger "ready to fight" energy.
- Turn the battle HUD into a combat frame with clearer hierarchy, brighter badges, and less product-panel feeling.

### Experience Changes
- Character cards emphasize role, perk, and stats at a glance.
- Weapon cards emphasize firing style, impact, and rhythm instead of only a name and tag.
- HUD gains louder labels, brighter live status, stronger build strip, and crate-like item rack styling.

### Scope
- Add lightweight display metadata to character and weapon catalogs.
- Update loadout screen/component markup.
- Update battle screen markup.
- Refresh shared component styles and small-screen behavior.
